# Animated ASCII screensaver

`mabinogion.txt` is a braille ASCII rendering of the dragon emblem from the Mabinogion book spine. Omarchy animates this artwork with its built-in TTE effects when the screensaver runs.

To use it on Omarchy:

```sh
install -Dm644 screensaver/mabinogion.txt ~/.config/omarchy/branding/screensaver.txt
```

The normal Omarchy idle screensaver will then animate the emblem. Run `omarchy screensaver` to launch it manually.
